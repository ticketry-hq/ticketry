_launch contract

The single shared launch path. Keyword-only scalar inputs — already-built launch facts, no init dict, no self, no profile, no cols/rows. Returns the run id on success; raises on failure.
SIGNATURE
async def _launch(*, agent, project_id, module_id, task_id, argv, cwd, design_dir, scope, doc_rel_path, workspace_slug, agent_run_id) -> str
INPUTS
All eleven are plain scalars/lists the caller already computed. agent_run_id is required and non-null — both callers mint it upstream (the WS path mints before _build_prompt; spawn_run mints in Slice 2). argv is the raw agent command before hook injection. workspace_slug replaces today's inline getattr(profile, "workspace_slug", None) — the caller reads it off the profile and passes the value.
STEP 1 — INJECT
Read WORKTRACKER_MCP_URL env (default DEFAULT_MCP_URL); run the four inject_*_lifecycle_settings(argv, agent_run_id, …) in the existing order (claude, codex, gemini, agy); command = shlex.join(argv). Verbatim move of lines 811–816.
STEP 2 — PERSIST
Build the AgentRun row (id, project_id, module_id, agent, status="running", started_at minted inside _launch as today, workspace_slug, task_id, cwd, design_dir), then in one asyncio.to_thread worker: run.save(force_insert=True) → tmux.create_session(...), closing the thread connection in finally. The combined persist-and-create helper moves wholesale.
STEP 3 — WATCH
On success, documents_watch.start_watch(agent_run_id, design_dir, module_id, task_id, scope, publish=publish_lifecycle). Verbatim move of lines 870–877.
RETURNS
agent_run_id: str — the persisted, live run.
RAISES
LaunchUnavailable when the persist/create thread raises (tmux missing/broken or DB write failed). See Failure & Cleanup.
EXCLUDED
No cols/rows, no PTY spawn, no viewer reservation, no PtySession, no _pump, no self.send. Those are the consumer's viewer half. _build_prompt/_worktree_root are not called by _launch.

Consumer refactor — _spawn_persisted after the split

The method keeps its True = handled / False = fall back return contract and its full signature. Its launch half becomes one awaited call to _launch; its viewer half is unchanged.

Launch half delegated

  1. Read scalars off init/profile (agent, project_id, module_id, workspace_slug).
  2. try: await _launch(agent=…, project_id=…, module_id=…, task_id=task_id, argv=argv, cwd=cwd, design_dir=design_dir, scope=scope, doc_rel_path=doc_rel_path, workspace_slug=…, agent_run_id=agent_run_id).
  3. except LaunchUnavailable as exc: log the existing warning, return False (caller runs the direct-PTY fallback as today).

Viewer half stays verbatim

  1. Mint session_id; _reserve_tmux_viewer → on clash send session_already_attached, return True.
  2. PtyProcessUnicode.spawn(tmux.attach_argv(...), dimensions=(rows, cols)) — the only place cols/rows are used.
  3. Build PtySession, register in SESSIONS, refresh_client_size, send ready, _pump; each error path releases the viewer and return True.

Module-aliasing note (why tests stay green): launch.py does from terminals import tmux, so launch.tmux and consumers.tmux are the same cached module object. The test suite's monkeypatch.setattr(consumers.tmux, "create_session", boom) mutates that shared module, so _launch sees the patched create_session (and tmux.TmuxSessionError) without any test edit. Same reasoning for documents_watch and AgentRun, which the tests reference by import rather than patch.

Decisions resolved in this LLD

Open calls the ticket left to the implementer, decided here so the slice is decision-complete.

Where is started_at minted?Inside _launchIt is launch state, not viewer state — keeps spawn_run from having to pass a timestamp. Verbatim move.
Is agent_run_id minted in _launch?No — required argBoth callers already mint it upstream (the WS path embeds it in the prompt; #715 mints before calling). Making it required keeps _launch a pure launch primitive with no hidden id source.
Where does the fallback warning log live?consumers.pyFalling back to a direct PTY is consumer-specific. _launch raises silently after cleanup; the consumer logs at the catch site, preserving today's message.
