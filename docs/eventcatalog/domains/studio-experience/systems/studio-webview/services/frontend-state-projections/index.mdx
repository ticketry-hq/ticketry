## Projection map

| Projection | Typical consumer | Reconciled by current status feed |
| --- | --- | --- |
| Backlog and task collections | boards and lists | yes, for workflow-state moves |
| Issue detail records | ticket detail views | no |
| Workflow-state catalog | selectors and cards | yes |
| Agent-run activity | terminal and activity UI | yes |

The same `work_item_id` can exist in multiple frontend projections. Updating one
projection does not imply that another has been invalidated.
