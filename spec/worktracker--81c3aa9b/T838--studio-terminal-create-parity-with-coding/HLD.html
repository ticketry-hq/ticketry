The Contract

The shared launcher owns the mechanics; Studio owns target resolution and context text.

INPUT

One epic/module

Normal create opens the existing epic picker. Add-under and surface-specific actions may imply one epic and skip the picker.

One chosen module before launch
PROMPT

Typed text plus advisory context

Inline text becomes the initial prompt. Empty button/shortcut entry opens PromptInput. Parent, state, sprint, and source surface are appended as context.

No direct field writes
RUN

Same planning terminal

AgentPicker always appears. The launcher opens a no-task scratch session with isPlanning true, using the existing backend planning prompt.
