Verdict

T687-5 cannot proceed directly for the whole ported coding surface. The current checked-in OpenAPI schema and scratch-generated SDK cover the WorkTracker contract under /api/work-tracker, but every root-mounted Muxed host family checked here is missing: terminals, runs/lifecycle, documents/assets/fs autocomplete, worktrees, and settings/config/profile.

The follow-up is contract/SDK work related to CODIN-668: either expand the SDK-exported schema to include the host REST surface or generate a second host client. The opaque document asset route may remain a plain URL builder, but it still needs an explicit decision.
