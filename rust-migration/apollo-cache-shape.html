What to take away. The tree the UI renders does not live in this cache — there is still no nested tree anywhere. The board reads the task list ref array plus each row's fields and rebuilds the shape from parent, exactly like today. What changes is plumbing you no longer write: the byId fan-out loop disappears (normalization is automatic on every query, forever), and the skip-while-mutating guard disappears (button 2 — the optimistic layer sits above the table, so refetches can't fight it). What relocates rather than disappears: the state_revision rule becomes one declared merge policy on WorktrackerIssue (button 3), and the snapshot/resync protocol keeps feeding AgentRun rows (button 4).
