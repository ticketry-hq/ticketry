Behaviour spec

ElementBehaviour
Worktree switcherReplaces the left column. Dropdown lists module checkout then task worktrees, each with a status dot and one-phrase state. Typing filters. Selecting loads that checkout in place. Same width and dot semantics as the toolbar chip.
Status chipsTwo at most: working tree (uncommitted · ahead) and pull request. Hover shows the full reason text the backend returns. Chips are read-only; clicking one opens the inspector to that section.
Primary buttonOne button, label derived from state: dirty → Commit & push; clean and ahead → Push; pushed, no PR → Create PR; PR merged → Merge locally; merged locally → Clean up. Disabled with a tooltip reason when nothing applies. Confirmation is a popover anchored to the button that names the branch and what will be published.
Branch togglearia-pressed, aria-controls the inspector. ⌘I toggles from anywhere in the workspace; esc inside the inspector closes it and returns focus to the toggle. Open state persists per session in the existing Apollo local-state store.
Inspector320px, appears instantly with no animation; the diff pane absorbs the width. Sections: Status, Pull request, Local merge, Worktree. Each is a native details with a state chip in its summary. Section open state persists with the inspector state.
ErrorsEvery red message renders inside the section it belongs to with the resolving actions on the same card. Nothing red appears without a button next to it. Action failures from the toolbar show as a one-line alert under the toolbar with a Retry.
FilesGrouped: uncommitted first, then committed since base. Rows: status letter, directory truncated from the left, filename never truncated, +/- fixed width. j/k move, Enter focuses diff, [/] step files from the diff.
Diff headerStatus letter, path, counts, position "5 / 34", prev/next. Empty state: "Select a file, or press j."
