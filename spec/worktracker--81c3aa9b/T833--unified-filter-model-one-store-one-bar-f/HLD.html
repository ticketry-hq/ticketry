Unified Issues Filter Model

One project-scoped filter model and one Issues filter bar for the List and Board layouts. The same selection follows layout switches; each layout decides how to interpret axes whose visual effect differs.

Refined Scope

The current code has two stores and two bars. This ticket replaces that split, but does not create the shared Issues page container; CODIN-832 owns that container and must land first.

Canonical model

One project-scoped filter shape

Search, epics, sprints, states, priorities, and show-subtasks live together. Empty arrays mean all. Existing epics and sprints sentinels stay valid.

Canonical bar

One IssuesFilterBar

Mounted once in CODIN-832's shared header. It replaces FilterBar and BoardFilterBar.

Consumer boundary

Story Map shares the store

Story Map keeps its planning controls but reads and writes the same project-scoped epic, sprint, and state axes. It does not mount the Issues bar.
