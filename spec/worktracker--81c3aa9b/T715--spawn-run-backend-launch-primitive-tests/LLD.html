Backend launch primitive spawn_run()

A keyword-only async spawn_run(...) in server/apps/terminals/launch.py that starts a coding-agent run for a task with no human at a WebSocket, producing a run indistinguishable from a human-started one (detached tmux session, real terminal the ticket view attaches to on demand) and returning the agent_run_id. It is pure composition over already-shared parts: Slice 1's _launch plus the #724-extracted neutral seams prompt_builder and agents.commands. No relocation, no consumer edits, no migration, no frontend.

The flow: spawn_run mirrors the consumer's launch half, minus the WebSocket

spawn_run reproduces lines 141–221 of consumers._orchestrate — resolve profile, compute cwd, mint id, build the task prompt, get argv, call _launch — but with no _send_error, no viewer, and no direct-PTY fallback. spawn_run contract

Keyword-only. Returns the run id on success; raises on every failure (no WS to send an error code to). Async callers await it; sync callers wrap with async_to_sync(spawn_run)(...).
SIGNATURE
async def spawn_run(*, agent: str, project_id: str, module_id: str, task_id: str, initial_prompt: Optional[str] = None, scope: str = "task") -> str
STEP 1 — PROFILE
_resolve_profile_index(); on None raise NoProfileSelected (the existing no-profile path). Else profile = cfgmod.Config().profiles[idx]; module_folder = profile.module_folders.get(module_id) or None (dropped if not a dir); cwd = module_folder or expanduser("~"). Mirrors consumers._orchestrate 141–150 verbatim.
STEP 2 — MINT
agent_run_id = uuid.uuid4().hex — minted before the prompt build, exactly as the WS path (the task design dir embeds run_id[:8]).
STEP 3 — PROMPT
await _build_prompt(idx, is_planning=False, is_instant=False, is_doc_chat=False, instant_prompt=None, project_id, module_id, task_id, initial_prompt=initial_prompt, agent_run_id, module_folder, doc_rel_path=None, doc_id=None, persist_task_id=task_id) → (prompt, design_dir, worktree_cwd, err). The task branch fetches the task, applies #587 worktree rooting (returns worktree_cwd), preps the design dir (#521), and threads initial_prompt through build_context_prompt(... additional_prompt=initial_prompt ...). On err, raise (see Error Surfacing).
STEP 4–5 — CWD + ARGV
if worktree_cwd: cwd = worktree_cwd (#587). argv = get_agent_command(agent, prompt); if the result is the ["echo", "Unknown agent: …"] sentinel, raise ValueError("unknown_agent") — mirrors the consumer's guard.
STEP 6 — LAUNCH
return await _launch(agent=agent, project_id=project_id, module_id=module_id, task_id=task_id, argv=argv, cwd=cwd, design_dir=design_dir, scope=scope, doc_rel_path=None, workspace_slug=getattr(profile, "workspace_slug", None), agent_run_id=agent_run_id). _launch injects hooks, persists the run, creates the detached tmux session, starts the watcher, and returns the id.
RETURNS
agent_run_id: str — the persisted, live, detached run.
RAISES
NoProfileSelected (no profile) · ValueError (prompt-build error code / unknown agent) · LaunchUnavailable (tmux/persist failure — orphan row already deleted by _launch). Never falls back to a direct PTY.
EXCLUDED
No viewer reservation, no PtySession, no cols/rows, no self.send, no direct-PTY fallback. Scope is "task" only; no dedup (the "already running?" check is #700's ready-set, out of scope).

Error surfacing — WS error codes become exceptions

The consumer answers failures by sending an error code over the socket and returning. With no socket, spawn_run raises. Each WS branch maps to one raise; nothing is swallowed.
WS path (consumers)spawn_run behaviorRationale
no_profile_selected (index None, or _build_prompt race)raise NoProfileSelected"Surfaces the existing no-profile path" as the ticket asks; NoProfileSelected is the canonical signal already raised by resolve_profile_index.
_build_prompt err code (task_id_required, task_fetch_failed, module_not_found, …)raise ValueError(err)These are input/context failures, not launch failures. The error code is preserved verbatim as the exception message for the caller (#716 tracer) to log.
unknown_agent (echo sentinel from get_agent_command)raise ValueError("unknown_agent")Same guard the consumer applies before spawning; an unbuildable command must never reach _launch.
tmux missing/broken · DB write fails (inside _launch)propagate LaunchUnavailable_launch already deletes the half-inserted row before raising, so no orphan AgentRun leaks. spawn_run does not catch it — there is no fallback (that was consumer-only).
