Task-Scope Dependencies: Indented Subtasks

Show the focused task's sub-task tree inside the Dependencies task scope, without changing dependency-hop semantics or adding backend surface.
Parent: CODIN-698 Frontend-only target No dependency inheritance
Scope System Shape Indented View Trace Acceptance

Build Scope

The feature answers one visibility gap: a selected task can have work hiding under it, and Task scope currently shows dependency neighbors but not the task's children.
In

Focus descendants

Build a descendant tree from loaded work items using parent_id, rooted at the selected task.

In

Indented context panel

Render children inline under the focus task with depth indentation, key, title, state, priority, and child count.

Out

Graph semantics

Do not treat children as dependency hops. Dependency nodes remain driven by blocked_by_ids and blocks_ids.

System Shape

Click a node. Green is the new display seam, blue is existing Dependencies code, violet is existing hierarchy logic that should be reused or mirrored.
Click a diagram node for responsibilities and non-responsibilities.

Indented View

The focus task remains visible as the anchor. Children are context, not dependency expansion.
