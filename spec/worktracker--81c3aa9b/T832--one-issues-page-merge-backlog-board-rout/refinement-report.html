Strongest Version

The page identity becomes /projects/:projectId/issues. List and Board are display layouts inside that page, not sibling destinations. The layout switcher writes local UI state and never navigates.

Hard question answered

What keeps T832 from swallowing T833?

T832 may create the container slot where one filter bar will live, but it must not delete or consolidate the two filter models. Until CODIN-833 lands, the HLD can show a temporary adapter: List renders the current FilterBar, Board renders the current BoardFilterBar, both inside the one header/container.
