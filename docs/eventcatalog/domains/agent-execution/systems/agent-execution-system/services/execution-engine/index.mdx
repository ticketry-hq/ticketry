The graph read is a projection of current WorkTracker hierarchy and dependency
edges. A campaign schedules only the root's direct children. `GraphRun` stores
the armed root and execution mode. Each `LaunchedTask` stores the durable launch
claim for one direct child before Ticketry asks the terminal runtime to act.
