Style scoping

The two apps share a byte-identical color palette and the font-mono stack, so Studio's single Tailwind build (its content glob already scans ./src/**) generates every utility class the copied code uses. Only two gaps need closing.

Known cosmetic nuance (documented, not fixed): Studio overrides Tailwind's fontSize scale (xs=11px, sm=12.5px, base=14px) vs Muxed's defaults (12/14/16px). Since utilities come from Studio's one build, Muxed text renders a touch denser. Acceptable for the tracer bullet; a restyle pass is deferred.
