In the proposed view, the Filters button shows a dot + count when any axis is set; the search box inside filters all sections at once (try “re” or “sprint”); States acts as column visibility — unchecking shows fewer board columns. Empty = all.

What changes

  • Three separate Epics/Sprints/States buttons collapse into one Filters popover with stacked, collapsible sections.
  • A single search box filters across all axes (WorkTracker's searchQuery), not per-dropdown.
  • Each section: (N) count, chevron collapse, and View all / less past 5 rows.
  • An applied-chip row with per-value × and Clear all — the part you liked.
  • Display popover holds Show sub-tasks + Group by epic.

What stays identical

  • Same planningFilterStore axes (epicIds / sprintIds / stateIds), same NO_EPIC / BACKLOG_ROW sentinels.
  • States is still the Board column axis, not a card-level filter.
  • Board search, priority chips, drag/drop, rank, selection, nav untouched.
  • Planning axes stay isolated — never written into backlogStore.filters.
