## Domain language

This is the domain model behind the tickets visible in Studio. A **work item**
is the canonical term; issue, ticket, task, module, and project are views or
specializations. A **workflow** is a directed graph, and a **launch binding**
selects how an agent should be launched for a work-item type and workflow state.

## Intended ownership

The backend database is authoritative. Studio holds projections for interaction
and must reconcile them from snapshots, deltas, or explicit refetches.
