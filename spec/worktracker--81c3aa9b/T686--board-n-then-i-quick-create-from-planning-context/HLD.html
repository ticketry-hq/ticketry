Board N then I Quick Create

Replicate WorkTracker's board-mode N then I quick-create flow in WorkTracker, dependent on #683's shared planning filters. The shortcut opens the existing issue composer from Board mode and seeds only unambiguous planning context.
Depends on #683 Frontend-only Board mode only No backend change
Scope System Shape Trace Files Acceptance

Scope

Board gets the planning shortcut; every other surface keeps its current create behavior.

Shortcut

When the active view is Board and focus is not in a text-entry control, pressing N then I opens create issue.

  • Case-insensitive keys
  • Short timeout between keys
  • Esc cancels the chord

Planning Context

Seed fields only when #683 planning filters are singular.

  • One epic: parent_id
  • One sprint: sprint_id
  • One visible state: state_id

Guardrails

Do not guess through ambiguous filters.

  • Multi epic/sprint/state stays blank
  • No epic sentinel means parent blank
  • Backlog sprint sentinel means sprint blank

Clickable Shape

Click a node to inspect responsibilities and explicit non-responsibilities.

N then I

Board-local keyboard chord that opens issue create.

  • Checks active view is Board
  • Ignores typing targets and open inputs
  • Does not implement WorkTracker plain-I assign-to-me
