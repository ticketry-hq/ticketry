C1 · Search & quick-filter parity

Find anything fast

A text-search box that narrows the loaded backlog/board by key or name, a priority quick-filter on the backlog, and ⌘K/“/” jump-to-issue-by-key.

G10 G11 G18
FEHighMed
Client-side over the already-loaded item set; reuses backlogStore.filters. Search shared between Backlog and Board surfaces. No new endpoint.
C2 · Multi-select & bulk actions

Edit many at once

Click / ⌘-click / ⇧-click selection on backlog & board, a bulk action bar to set state, sprint, priority, or delete across the selection.

G09
FEHighMed-Hi
Implements the Jira selection model agreed in S1/S2 and deferred. Each bulk op is a fan-out of the existing optimistic patchWorkItem with rollback. Zero backend.

Backend gaps — flagged, not built

Per the story’s charter, backend work is a last resort and is surfaced here rather than silently implemented. Each item names the exact missing surface so the cost is visible before any child is filed.
B1 · SMALL · ADDITIVE

Expose timestamps (G07)

Issue.created_at/updated_at exist on the model but not on WorkItemOut. Add two read-only fields; no migration. Lowest-risk BE change — recommend bundling into C8.

B2 · SMALL-MED

Editable labels (G06)

Labels resolve on read but WorkItemPatch has no labels field. Add a label set-replace write path (and SDK mirror). Recommend bundling into C8.

B3 · MED · OPEN QUESTION

Attachment upload (G02+)

Display rides the existing attachments[] payload (free, in C4). Upload needs a new multipart route + a storage decision. File as C9 only if capture is in scope.

B4 · HEAVY · RECOMMEND DEFER

Comments / activity feed (G08)

No Comment model or history exists. A full feed is a new model + routes + SDK + FE — the largest single item here and the least essential for a single-user tracker. Recommend deferring to its own story, not a #630 child.

Recommendation: ship C1–C7 (all FE-only) first; file C8 (B1+B2) only if timestamps/labels are wanted now; treat B3/B4 as their own follow-ups. This keeps #630’s children overwhelmingly frontend and honors “backend = last resort.”
