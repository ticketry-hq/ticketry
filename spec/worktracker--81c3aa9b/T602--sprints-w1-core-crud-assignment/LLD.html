def _sprint_progress(sprint): """Done/open counts from member tasks' state group. Read-only derivation.""" qs = Issue.objects.filter(sprint=sprint, type="task") total = qs.count() done = qs.filter(state__group__in=("completed", "cancelled")).count() return {"total": total, "done": done, "open": total - done} # list_sprint_work_items: 404 first, then the flat membership filter @router.get("/sprints/{sprint_id}/work-items", response=List[WorkItemOut]) def list_sprint_work_items(request, sprint_id: uuid.UUID): get_object_or_404(Sprint, pk=sprint_id) return _task_qs().filter(sprint_id=sprint_id) # inside the EXISTING patch_work_item, beside the parent_id branch: if "sprint_id" in data: # exclude_unset keeps explicit null → clears issue.sprint_id = data["sprint_id"]

Edge handling

Green = locked decision realized in code. Amber = behavior a test pins.
EDGE · delete

Delete unsprints, never deletes

SET_NULL at the DB level. Test: assign a task, delete the sprint, assert the task still exists with sprint_id is None.

EDGE · clear

Explicit null clears the FK

Patch with {"sprint_id": null} → exclude_unset keeps the key → issue.sprint_id = None. A patch that omits sprint_id leaves it untouched. Both pinned by test.

EDGE · progress

Null-state tasks count as open

done filters state__group in (completed, cancelled); everything else — including a task with no state — falls into open. Empty sprint → 0/0/0.

EDGE · no cascade

Subtask sprint independent of parent

Membership is the flat sprint_id column; assigning a parent does not touch children. list_sprint_work_items is a flat filter, not a tree walk.

DECISION · close

Closing a sprint moves nothing

status=completed is a label change only; incomplete tasks keep their sprint_id until manually re-assigned. No carry-over logic.

DECISION · frozen

Provision & import untouched

No sprint is minted at provision or WorkTracker-import. The 13 frozen routes keep their exact signatures; only patch_work_item gains a field.
