      Decisions

      • D-1 SectionHeading has three levels; the section label reuses the eyebrow class exactly; title replaces SETTINGS_SECTION_HEADING_CLASS.
      • D-2 EmptyState inline is text only (row padding via className px-3 py-2); pane is the shared centred layout.
      • D-3 LoadingState always role status and always appends the single … character.
      • D-4 ErrorLine always role alert in lifecycle-danger; variants inline, banner, pane.
      • D-5 SettingsStatusLine keeps its tone union; danger delegates to ErrorLine banner; static tone="danger" sites call ErrorLine directly; the two heading constants are deleted.
      • D-6 Every call site passes the as that reproduces today's element; no new heading roles.
      • D-7 className is spacing and placement only; dividers move to a wrapper.
      • D-8 Empty and error copy verbatim; loading labels get … appended; bare … lines become Loading modules / Loading stories.
      • D-9 Tokens only; NotifyUserModal info/warning/error map to lifecycle idle/attention/danger; tailwind.config.ts unchanged.
