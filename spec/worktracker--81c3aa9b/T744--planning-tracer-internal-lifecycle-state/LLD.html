Scope

The implementation must add Issue.lifecycle_state as a durable internal pipeline axis. It must not create visible lifecycle states, move Issue.state, generate artifacts, create leaf tasks, register blocked_by edges, or launch agents.

Build

  • Nullable lifecycle field, migration, enum values, transition table, and visible pairing map.
  • One guarded lifecycle service raising InvalidTransition.
  • Read-only lifecycle fields on WorkItemOut and guarded HTTP write endpoint.
  • MCP set_lifecycle tool routed through HTTP guard.
  • Execution retrofit that persists lifecycle and removes the phantom LLD visible-state gate.
  • Drawer chicklet and picker that show only server-provided legal transitions.

Do Not Build

  • No seeded HLD/LLD visible states and no new visible state group.
  • No lifecycle values in board columns, swimlanes, filters, state picker, or workflow config.
  • No engine auto-sync of visible workflow state.
  • No lifecycle blocked value; use visible Blocked and blocker edges.
