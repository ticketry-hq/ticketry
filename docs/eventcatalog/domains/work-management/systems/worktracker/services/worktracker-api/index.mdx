## Responsibilities

- Own validation and persistence for the planning model.
- Expose configuration, workflow, attachment, reorder, dependency, and transition operations.
- Publish snapshots and selected deltas to Studio through `/ws/status`.

## Important contract boundary

The status feed currently publishes committed **state moves**. It is not a
general work-item change stream and does not publish deletion tombstones.
