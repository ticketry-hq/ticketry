# Single focus store replaces recency-based workspace arbitration

Workspace-scoped chords (Cmd+Arrow tab navigation) used an ephemeral ownership system separate from pane focus: every mounted task workspace carried a monotonic interaction stamp, and the most recently interacted workspace won events whose target sat outside all of them (CODIN-1073). With keyboard resolution centralizing in the keymap registry (ADR 0001) we make the focus store the single source of truth: workspace chords go to the focused workspace, an open issue drawer counts as focused while open, and the recency-stamp arbitration is deleted. We chose predictability (the visibly focused surface always receives the chord) over the old "last touched wins" heuristic, whose winner was invisible to the user.
