# Security policy

## Supported versions

Ticketry is still in prerelease development. Security fixes are made on the
latest commit of the `main` branch. Older commits and locally built binaries do
not receive separate security updates.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability reporting form in the Security tab of this repository.

Include the affected commit, reproduction steps, impact, and any suggested
mitigation. Please avoid accessing data that is not yours or disrupting other
systems while testing.

The maintainers will acknowledge a report within seven days and will coordinate
disclosure after a fix is available. If the report does not describe a security
issue, it may be moved to the public issue tracker with the reporter's consent.
