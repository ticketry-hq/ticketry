OPEN QUESTION · DOM NESTING

How should Popover handle button nesting?

Currently, Popover wraps the trigger(open) return value in a <button>. The pickers return `<span>` tags, meaning we get `<button><span className="border...">` which passes validation but is redundant. We will clean this up so Popover handles the HTML <button> element directly and the triggers represent the content inside it, or make it fully configurable.

OPEN QUESTION · BlockerPicker Style

Should BlockerPicker trigger share PickerTrigger styling?

Currently, BlockerPicker is styled differently (dashed border, rounded-full, text-focus-accent) compared to standard fields (solid border, rounded-md). We plan to support a variant="dashed" prop in PickerTrigger to preserve this style difference while standardizing the HTML layout.
