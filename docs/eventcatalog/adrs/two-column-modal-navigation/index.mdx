The two-column edit view has three zones: Stories list, tab strip, and active tab
body. Shift+Tab cycles zones; arrows follow visible geometry; Enter explicitly
engages the body; Cmd+Escape disengages it without changing zones.

This preserves terminal and agent ownership of Tab, Shift+Tab, and content arrow
keys while engaged.
