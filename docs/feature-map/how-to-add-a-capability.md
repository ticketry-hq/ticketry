# How to add a capability

Start here before writing code for a common task. Each row names the path with
the least handwritten code, its status, and where the detailed steps live. The
steps themselves stay in the linked feature-map section or skill; this guide
does not restate them.

Status labels:

- **Supported now**: the shared module exists; use it.
- **Transitional**: still in the code, being removed; do not extend it.
- **Proposed**: an owning Story will deliver it; until then follow the current
  pattern and cite the Story in your reuse record. Each Proposed row links the
  owning Story's spec, which records its decisions and current fallback;
  `npm run reuse:check` blocks a Proposed row whose owning Story is unlinked.

Paths are relative to `studio/src-tauri/crates/` for Rust and `studio/src/` for
the frontend unless a link says otherwise.
