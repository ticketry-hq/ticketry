    Preserved boundaries

      Decisions

      • D-1 One file per component; no barrel; no exported class helper.
      • D-2 Sizes xs, sm, md; xs exists because the footer is 24px and the dashed triggers are text-xs.
      • D-3 One look per variant: danger and danger-filled become danger; filled accents become accent-border primary.
      • D-4 Hover tokens use enabled:hover:.
      • D-5 Pending is shown with aria-busy (wait cursor).
      • D-6 dashed shows the open state from aria-expanded.
      • D-7 className is layout only.
      • D-8 icon requires aria-label in the type.
      • D-9 DialogFooter is props-driven: Cancel secondary md, then confirm primary or danger at md.
      • D-10 Single-action dialogs keep their wrapper and use one Button.
      • D-11 Inline forms, Settings Discard/Save bars and the ChangesToolbar popover keep their order and use plain Buttons.
      • D-12 The KeyboardSettings binding cell drops font-mono and the recording background; the label shows the state. No aria-pressed.
      • D-13 PickerTrigger keeps its variant prop: default to secondary sm, dashed to dashed xs, bare to ghost sm; crumb stays local.
      • D-14 ghost uses border-transparent (constraint from overhaulWorkItemAcceptance.test.tsx:190).

      Deferred copies (follow-up, not 05 acceptance)

      Intentional visual changes

      Settings primary changes from filled to accent border. Danger becomes one tinted style. Modal Cancel loses bg-pane-bg. Run actions use accent text. The ChangesToolbar primary changes from inverted to accent. The dashed PickerTrigger becomes muted dashed. StateCatalog ↑/↓ become borderless icon buttons. Onboarding filled buttons become accent border. Footer buttons gain a transparent 1px border and px-2. Every button gains a focus-visible ring. Behaviour is unchanged.
