const [copied, setCopied] = useState(false);
const copyLink = () => {
  if (!navigator.clipboard) return;            // no-op when unavailable
  void navigator.clipboard.writeText(
    `${window.location.origin}/issues/${drawerKey}`);
  setCopied(true);
  setTimeout(() => setCopied(false), 1500);
};

G04 — Keyboard navigation

One document-level keydown effect in the drawer host, plus the cursor gate that lets it own the arrows while open.
G04

Drawer keydown: Esc · ↑ · ↓

IssueDrawerHost.tsx · new useEffect
  • Listener reads stores via getState() (not hooks) so it stays stable — registered once, never re-subscribes as items/filters change. Re-keyed only by drawerKey so the "current" anchor is fresh.
  • Guard first: if (isTypingTarget(document.activeElement)) return; — bail inside any input/textarea/select/contenteditable so inline name/description editors keep their own typing + Escape.
  • Esc → close(). ↑/↓ → flatten, find current by key, step ±1, clamp [0, len−1], navigate(`/issues/${nextKey}`). preventDefault() on a real move so the drawer body doesn't scroll.
  • Current key not in the flattened set (cold deep-link before hydrate) → no-op.
useEffect(() => {
  if (!drawerKey) return;
  const onKey = (e: KeyboardEvent) => {
    if (e.metaKey || e.ctrlKey || e.altKey) return;
    if (isTypingTarget(document.activeElement)) return;
    if (e.key === "Escape") { e.preventDefault(); close(); return; }
    if (e.key !== "ArrowUp" && e.key !== "ArrowDown") return;
    const items = useBacklogStore.getState().items;
    const filters = useBacklogStore.getState().filters;
    const modules = useStudioStore.getState().modules;
    const keys = flattenVisible(groupBacklog(items, modules, filters), NONE, NONE)
                   .map((i) => i.key);
    const idx = keys.indexOf(drawerKey);
    if (idx === -1) return;                          // not in loaded set
    const next = e.key === "ArrowDown"
      ? Math.min(keys.length - 1, idx + 1)
      : Math.max(0, idx - 1);
    if (next !== idx) { e.preventDefault(); navigate(`/issues/${keys[next]}`); }
  };
  document.addEventListener("keydown", onKey);
  return () => document.removeEventListener("keydown", onKey);
}, [drawerKey, selectedProjectId, navigate]);
// NONE = module-level const NONE = new Set<string>()  (shared empty collapse set)
G04·gate

Cursor yields while drawer open

useBacklogCursor.ts + BacklogList.tsx
  • Add a 3rd param enabled: boolean = true to useBacklogCursor; mirror into enabledRef; first line of onKey becomes if (!enabledRef.current) return;.
  • BacklogList passes useUiStore((s) => s.drawerKey) === null → cursor goes inert whenever a drawer is open. (A document/window listener can't be pre-empted by the later-registered drawer listener, so gating the source is the correct fix, not stopPropagation.)
  • No behavior change when no drawer is open — j/k and ↑/↓ still drive the row cursor exactly as #642 shipped.

The ↑/↓ walk & the collision, step by step

Click a step for its mechanics and edge cases. Steps 1–5 are the drawer's own handler; step 0 is the gate that makes it the sole owner of the arrows.
  1. 0Gate: drawer open → useBacklogCursor disabled (drawerKey === null is false), so only the drawer's listener acts on ↑/↓.
  2. 1Guard: bail if a modifier is held or activeElement is a text-entry surface.
  3. 2Flatten: flattenVisible(groupBacklog(items, modules, filters), NONE, NONE) → the filtered Epic→Story→Sub-task order, collapse-agnostic.
  4. 3Locate: keys.indexOf(drawerKey); −1 → no-op.
  5. 4Step + clamp: ↓ = min(len−1, i+1), ↑ = max(0, i−1). No wrap.
  6. 5Navigate: only if the index actually changed → navigate(`/issues/${nextKey}`); route-sync reopens the drawer.
