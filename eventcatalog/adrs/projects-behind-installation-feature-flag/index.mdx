Projects remain real in the tracker: work items, states, types, launch bindings,
and workflows are project-scoped. A local installation flag only gates their UI
surface.

The flag is installation configuration rather than database data. The API and
MCP surfaces remain project-scoped, making the decision reversible without a
data migration.
