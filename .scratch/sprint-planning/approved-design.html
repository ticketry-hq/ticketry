Sprint planning in Studio

A working mockup with example data. Plan and Changes are fixed tabs at the start of the tab strip. In a sprint's Plan view, you work through one epic at a time: open the epics you want to plan as tabs, and close each one when you're done with it. The flow has three steps. First, set goals on a sprint in the Sprints list. Next, an agent looks for stories that fit them in the background. Then you plan, and the agent's suggestions are waiting in the backlog. Nothing joins the sprint until you accept it.

Epic tabs

  • You plan one epic at a time. The epic tabs work like the module tabs: open epics with + Add epic, switch with ⌥ ], and close with ×.
  • Done with this epic closes the current tab and moves to the next one, so you can work through the list in order.
  • Closing a tab doesn't remove anything from the sprint. If suggestions are still waiting, the toast says so, and the + Add epic menu shows the count so you can find them again.
  • The sprint pane always shows the whole sprint. Stories from other epics stay visible but dimmed.

Goals, then agents, then planning

  • 1. Goals. Each sprint card in the Sprints list has its own goals (G1, G2…). You set them before planning.
  • 2. Agent. ✦ Find stories starts an agent in the background, and you can leave while it works. It reads the goals and the backlog and returns suggestions only. It never changes what's in the sprint.
  • 3. Plan. When it finishes, the sprint card says how many suggestions are ready and links to Review in Plan. In Plan, suggestions sit at the top of each epic's backlog. Each names its goal and says why it fits. Use ✓ to add one, × to dismiss it, and Undo to reverse either.
  • The Plan header stays one line. It shows the goal count (hover for the goals) and how many suggestions are left to review.

Removed for now

  • Story Map.
  • Sprint length buttons (1w–4w). Sprints keep their dates, and setting length can come back later.
  • The modules sidebar. Modules are reached only through the top tabs.
  • Selecting several epics at once. One epic tab is active at a time.
