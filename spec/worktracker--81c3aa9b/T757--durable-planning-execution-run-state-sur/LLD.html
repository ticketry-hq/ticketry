Durable Planning / Execution Run-State

Implementation harness for persisting the execution engine's private run-state so the one-run-per-task guard survives an ASGI restart. The plan keeps lifecycle semantics in CODIN-744 and failure recovery manual-only.
Phase: LLD EngineRun + GraphRun DB-backed duplicate guard Graph rebuild after cache loss No liveness inference
Scope Model Schema Surface Change Map Sequence Tests Risks Acceptance

Scope

Two implementation slices. S1 fixes the headline duplicate-launch risk; S2 makes graph state restart-durable without storing derived edges.

Build

  • S1: durable single-task EngineRun row keyed by task_id.
  • Planning-run 409 guard reads the durable row, not process memory.
  • Launch success, launch failure, completion observer, and manual release write durable state.
  • S2: durable GraphRun header plus node state from EngineRun rows.
  • GET execute-graph rebuilds after _graph_registry loss.

Do Not Build

  • No timeout, boot sweep, passive liveness check, or dead-marker inference.
  • No agent-facing failure-report MCP tool.
  • No dependency on CODIN-756.
  • No new phase or lifecycle semantics.
  • No public API or MCP surface beyond retargeting existing routes.

Data Model

Rows store the same facts the engine already carries in memory. Timestamps help debugging only; they are not a liveness signal.

engine_runs

task_idUUID primary key; one row per task.
project_id / module_idTask context for scoped reads and diagnostics.
agent / phase / statusExisting engine facts; no new phase names.
agent_run_id / errorDetached tmux run binding and launch/release reason.
created_at / updated_atAudit and debugging only.

graph_runs

root_idUUID primary key for the graph root task.
project_id / module_idCopied from root context.
agentDefault agent used for graph launches.
created_at / updated_atHeader audit fields.
edgesNot stored; derived from current blocked_by.

Implementation Sequence

Decision-complete build order. Select a phase to see the mechanic and edge case it covers.

Test Plan

The key regression is restart simulation: clear memory and prove durable rows still gate launch and rebuild graph state.

Guard

Seed a running row, clear _registry, POST planning-run, assert 409 and no spawn.

Fresh Launch

No durable row launches and persists running with run id and context.

Spawn Error

Launch exception persists failed with the existing error contract.

Completion

Observer seam flips matching durable running row to done.

Manual Release

Release clears or rewrites the durable row; the next POST can launch.

Concurrency

Two same-task launch attempts cannot create two rows; loser follows 409/existing-row path.

Graph Restart

Clear _graph_registry; GET returns nodes with status, agent run id, and error intact.

Derived Edges

blocked_by changes affect rebuilt graph without stored edge rows.

Negative Liveness

No timeout, startup sweep, AgentRun status, or missing tmux marker flips running to failed.

Risk Controls

Each control maps to a failure mode from refinement.
RiskControl
Duplicate launch raceUse EngineRun.task_id primary key/unique constraint, not only a preflight read.
Accidental death inferenceEnumerate every mutation site: launch success, launch failure, completion observer, manual release.
Lifecycle confusionDo not validate board progress from EngineRun.phase; CODIN-744 owns published lifecycle.
Graph driftStore root/header and node status only; derive edges from current blocked_by.
Cache divergenceFocused tests clear memory and still pass through durable reads.
Release mismatchCODIN-755 must release the durable row in the same implementation window.

Acceptance Signal

Green signal: after an ASGI restart simulation, an existing running planning run still returns 409 without spawning a duplicate; graph state survives cache loss with no lost agent/error facts; and no server path infers death or flips running to failed except launch failure or manual release.
