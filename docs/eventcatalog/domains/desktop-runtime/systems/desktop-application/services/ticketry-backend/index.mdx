## Composed surface

The sidecar mounts settings, run lifecycle, terminals, documents, worktrees,
execution, and WorkTracker routers below `/api`. It also exposes `/ws/status`
and `/ws/terminal`.

The attached OpenAPI document is regenerated from `studio_server.api` every time
the catalog starts or builds, so this page is the endpoint-level view of the
current backend rather than a hand-maintained route list.
