The Contract

This is a cleanup and keyboard parity slice, not a new execution system.

REMOVE

Tracked planning-run UI

Delete Refine, Split, the planning phase agent select, Release lock, and the associated pending/error/release note state from the drawer tab strip.

No postPlanningRun path from drawer
KEEP

Normal task agent launch

The existing + Agent affordance remains. It starts a task-bound terminal session with the selected agent and foregrounds the terminal tab.

No replacement with orchestrator yet
ADD

Board Enter launch

A focused Board card resolves task context, then opens AgentPicker in task-bound open mode with an explicit-context payload. The final agent choice launches the same terminal path as /coding.

AgentPicker gains explicit taskId/ticketSeq payload (ADR-0001)
