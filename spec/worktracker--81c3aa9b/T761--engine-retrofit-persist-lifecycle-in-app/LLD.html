Scope

This slice touches only the execution engine integration with the lifecycle guard. CODIN-744 owns the lifecycle model, API, MCP tool, and UI surfaces.

Does

  • Persist engine-owned phase boundaries through the guarded lifecycle service.
  • Complete split from lifecycle hld_approved.
  • Replace register precondition from visible LLD to lifecycle hld_approved.
  • Add reducer and driver tests around lifecycle writes and completion.

Does Not

  • Implement CODIN-744's model field, migration, HTTP endpoint, MCP tool, or drawer picker.
  • Create or seed HLD or LLD visible workflow states.
  • Synchronously move Issue.state.
  • Change split registration, leaf creation, prompts, or board behavior.

Test plan

Tests should prove the durable lifecycle path and lock out the old seeded-state dependency.

Reducer

  • Running split completes on lifecycle hld_approved.
  • Other lifecycle values are ignored.
  • Unrelated task and non-running split stay unchanged.
  • No reducer test sends to_state="LLD".

Driver

  • Launch boundaries call guarded lifecycle writes before spawn.
  • Guard rejection prevents spawn and records failure.
  • hld_approved chains register once.
  • Register precondition uses lifecycle only.

Failure

  • Spawn failure attempts lifecycle failed.
  • Graph cancellation maps through guarded terminal lifecycle.
  • Terminal rejection does not move visible state.

Regression

  • No test creates a visible LLD state.
  • No execution path calls a visible-state save.
  • Existing ready-set ordering still passes.
