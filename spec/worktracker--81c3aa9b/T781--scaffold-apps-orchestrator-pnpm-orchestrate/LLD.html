Scope Lock

This slice establishes the place where orchestration will live. It deliberately avoids the orchestration engine itself.

Build

  • New server/apps/orchestrator/ Django app package.
  • README and docstrings that state the import boundary.
  • Empty models.py with no migrations or tables.
  • No-op receiver connected to worktracker.signals.issue_state_changed.
  • pnpm orchestrate root script that starts the backend only.
  • Smoke tests for app load, receiver registration, and import boundary.

Do Not Build

  • No reducer, driver, node state, run header, retry, or budget logic.
  • No headless agent launch primitive.
  • No strategy pack loader or default strategy content.
  • No HTTP, MCP, Studio, or frontend trigger surface.
  • No WorkTracker lifecycle states.
  • No import from apps.execution or apps.terminals.

Launch Contract

The dedicated command is the only entry point that runs the orchestrator app.

Must Start

  • Django ASGI backend.
  • Orchestrator settings module.
  • worktracker app and signal seam.
  • apps.orchestrator AppConfig.

Must Avoid

  • Studio/Vite dev server.
  • tmux terminal launch or reconciliation.
  • apps.execution receiver registration.
  • Any frontend watcher.

Must Preserve

  • Existing local DB defaults.
  • WorkTracker auth env defaults.
  • ASGI HTTP serving shape.
  • No orchestrator routes yet.

Risks and Guards

The main risk is accidental coupling to existing execution or dev-stack startup behavior.
RiskGuard
Orchestrator imports the old executor.README/docstring rule plus static boundary test.
Launch path starts the full dev stack.Dedicated launcher script; do not delegate to pnpm dev.
Existing ASGI startup imports tmux behavior.Gate those hooks by settings or add a small orchestrator ASGI module.
Empty app creates migration churn.Keep models.py empty and add no migrations.
Receiver grows behavior too early.No-op/logging-only contract and tests that only assert registration.
Strategies placeholder looks implemented.Placeholder documentation only; loader remains out of scope.

Acceptance Signal

Accepted when: the plan clearly limits implementation to the orchestrator app scaffold, ASGI-only pnpm orchestrate path, and smoke tests proving app load plus signal receiver registration, while preserving the hard rule that apps.orchestrator never imports apps.execution.
