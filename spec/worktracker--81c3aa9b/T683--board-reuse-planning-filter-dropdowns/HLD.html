Decisions

Reuse store

Board reads planningFilterStore for epic, sprint, and state axes, including per-project persistence and stale-id reconciliation.

Replace module select

EpicsFilterDropdown replaces the single-module select so Board gains multi-select plus No epic.

State = columns

StatesFilterDropdown hides non-selected state columns and their cards; it does not add a second row-level state filter.

Do not merge all filters

Search, priority, show-subtasks, and group-by-epic remain Board/backlog filter concerns for this slice.

Out of scope

Acceptance signal
