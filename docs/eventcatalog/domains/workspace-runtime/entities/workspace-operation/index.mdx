SQLite and the local filesystem or Git cannot commit together. A Workspace
Operation is the record that closes that gap: it is prepared and committed
*before* the external mutation, claimed under a bounded lease while one worker
acts, and settled in the same transaction as the affected
[Document](/docs/entities/document) or [Worktree](/docs/entities/worktree) row
and its durable status fact.

Recovery never guesses. Startup reconciliation is bounded and repeatable: it
probes the re-resolved external subject before retrying, adopts an effect that
is already durable, executes again only what is provably absent, retains typed
conflict evidence rather than overwriting, and keeps a cleanup-pending
operation until its remnant is proven gone. An undecidable subject is isolated
by resource, so one stuck checkout cannot make the rest of the workspace
unusable.

The journal is an internal entity. It has generated SeaORM code but no public
GraphQL query or mutation bundle.
