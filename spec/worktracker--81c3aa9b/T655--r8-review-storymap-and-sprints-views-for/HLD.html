  • Update SprintRow.tsx to import and use formatSprintDates

RESOLVED · T655-Q1

Should SprintsLens sections and Backlog buckets be extracted too?

Decision: Keep them inline inside SprintsLens.tsx. They are relatively simple container segments (e.g. BacklogBucket), and extracting them would cause unnecessary file proliferation (needless churn) without improving comprehension.
