Every shortcut resolves through one registry. An action is identified by keymap
context and action id, with fixed precedence: modal, capture, focused pane, then
global.

A flat global chord namespace cannot express contextual Enter/Escape behavior;
separate configurable listeners cannot detect duplicates or render a coherent
legend.
